# Banking System using Java

## About the Project
This is a simple console-based Banking System application developed using Java. It allows users to perform basic banking operations such as depositing money, withdrawing money, and checking their account balance.

## Features
- Deposit Money
- Withdraw Money
- Check Account Balance
- Input Validation
- Exit the Application

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Scanner Class
- Switch Case
- While Loop

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/YashBhardwaj1508/Banking-System.git
```

2. Open the project folder.

3. Compile the Java file:

```bash
javac BankAccount.java
```

4. Run the application:

```bash
java BankAccount
```

## Default Account Balance
The application starts with an initial balance of 1000.
